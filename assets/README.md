# assets

Optional files. The site works without them.

| File        | What it does                                                                 |
| ----------- | ---------------------------------------------------------------------------- |
| `audio.mp3` | Background music ("aimbot.dll", original darksynth loop, 112 BPM, generated by `tools/track.py` – no samples, no licence issues). Starts when the visitor clicks "click to enter". Missing → no mute button. Swap in any mp3 with the same name and set `trackName` in `script.js`. |
| `bg.mp4`    | Optional background video behind the grid. Set `bgVideo: "assets/bg.mp4"` in `script.js`. Keep it short, muted-friendly and < 10 MB. |
| `party.mp3` | Easter-egg track for party mode ("oiia oiia (reez party mix)", 140 BPM, chant is formant-synthesised by `tools/party.py`). Swap in any mp3; beat effects assume 140 BPM (`PARTY_BPM` in `script.js`). |
| `avatar.webp` | Profile picture (208×208, shown at 104 px). Replace the file to change it. If it can't load, an "R" monogram is shown instead. |
